Licensing Charness

Charness is source available: the code is open to read, and you use it under one licence file.

Everything about the licence — when Charness is free, what you may do with the code, the prices for organizations, AI training, products that embed it, discounts and how to buy — is in LICENSE in the repository. This site restates none of it, so the file is the only place to read.

Buying

Buying follows the numbered steps in LICENSE, section 3.7, and works the same for a person and for an AI agent acting for its organization. Orders, invoices and questions go to charnesshub@gmail.com; there is no online checkout yet.
