Charness

Your coding agents grouped by project, not by chat, and reachable from anywhere, 24/7.

Most agent apps split everything into sessions or chats, and tracking dozens of them over time gets very hard, while keeping a project or a direction in your head stays easy. Charness (formerly TelegramCode) adds a level of grouping above the session: a topic is a project, a direction, a category or a theme. Sessions live inside it: the topic's agent works as their manager, starting the working sessions and keeping an eye on them, while the bot runs their lifecycle, so you talk to the project instead of to every chat.

The second idea is availability. Charness is self-hosted: it runs on your own machine or server and connects out to Telegram only, so there are no open inbound ports, and your agents are reachable from your phone at any hour. You bind each forum topic (or the bot's own DM) to a project folder and drive its OpenCode or Claude Code session by chat, voice, or file. Two topics can share a folder for parallel work.

What it does

  • Both agents. OpenCode over its native HTTP+SSE server, and Claude Code via tmux or json-stream.
  • From your phone. Type, send a voice note (transcribed with Whisper), or drop in a photo, file, or PDF.
  • No open ports. Outbound-only to Telegram, so it is comfortable to leave on a VPS.
  • Pinned question alerts. When the agent asks something, the bot pins it so even a muted topic notifies you once.
  • Scheduled and self-driving runs. Cron, one-shot, or N-times jobs per topic, and the agent can schedule itself.
  • Restart-safe. Sessions survive both a bot restart and an agent-server restart.
  • Raw terminal. /terminal binds a topic to a real shell in the project folder.
  • Agent-facing MCP. The agent sends files, images, and video back to you, posts multiple messages, and schedules itself.
  • 12 UI languages. MIT licensed, Node 22.12+.

Install

npm install -g charness (the command is charness; the former name, telegramcode, still works)

Put your bot token in one .env, launch from your projects folder, and bind a topic. Full setup is in SETUP.md.
